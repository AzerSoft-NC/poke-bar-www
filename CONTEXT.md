# www

Web application repository for poke-bar.

## Language

Visitor-facing copy is bilingual. **Default locale** is French (`fr`) at the site root; English (`en`) lives under the `/en` prefix.

## Glossary

| Term | Meaning |
|------|---------|
| Poke Bar | Brand / restaurant (Nouméa) |
| Les Quais | Primary v1 location (galerie commerciale) |
| BASE_PATH | URL subpath for temporary hosting (`/poke-bar`) |
| Menu PDF | Full menu download (`public/menu.pdf`) |
| Default locale | French (`fr`) — unprefixed URLs |
| Locale prefix | English (`en`) served under `/en` |
