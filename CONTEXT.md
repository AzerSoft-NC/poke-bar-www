# www

Web application repository for poke-bar.

## Language

Visitor-facing copy is bilingual. **Default locale** is French (`fr`) at the site root; English (`en`) lives under the `/en` prefix.

## Glossary

| Term | Meaning |
|------|---------|
| Poke Bar | Brand / restaurant (Nouméa) |
| Les Quais Ferry | One of the two Poke Bar locations (galerie commerciale, 8 rue Jules Ferry). Avoid: Place des Cocotiers |
| Ouen Toro | The other Poke Bar location |
| pokebar.nc | The public app: website and click & collect. Avoid: treating the Astro repo as the long-term site |
| admin.pokebar.nc | The backoffice app: order tracking and configuration. Separate from pokebar.nc |
| BASE_PATH | URL subpath for temporary hosting (`/poke-bar`) |
| Menu PDF | Full menu download (`public/menu.pdf`) |
| Default locale | French (`fr`) — unprefixed URLs |
| Locale prefix | English (`en`) served under `/en` |
